# UI Design Refinement: Clean SaaS Dashboard & Platform Aesthetic

Refactor the application design to match the clean, minimalist, and highly readable SaaS layout seen in professional dashboard templates (balancing modern appeal with professional simplicity—not overly neon/glowing, not outdated).

## User Review Required

> [!IMPORTANT]
> We will tone down excessive neon glows, reduce heavy rounded pill shapes (`rounded-[2.5rem]`), optimize typography font sizes for high legibility, and adopt a clean, structured SaaS card and layout aesthetic across the platform.

## Proposed Changes

### Global Styling & Typography
- **Font Sizes**: Increase base legibility, adjust heading weights from heavy `font-black` to balanced `font-bold` / `font-semibold`.
- **Card Styling**: Replace heavy neon glows and high-opacity colored orbs with clean, professional SaaS cards (`border border-slate-800 bg-slate-900/90 rounded-2xl shadow-md`).

### Navigation & Components
- Clean up Navbar and Footer to maintain the requested left 3-line menu and right logo layout with refined padding and readable font sizes.

## Verification Plan

### Automated & Manual Verification
- Review page layouts and component aesthetics for readability and clean SaaS visual balance.
